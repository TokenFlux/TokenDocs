# 邀请返利

邀请好友注册 TokenFlux，好友充值后可按页面显示的实际返利比例获得推理积分返利。

**前往邀请返利页面：[https://tokenflux.dev/affiliate](https://tokenflux.dev/affiliate)**

## 邀请步骤

1. 打开 [邀请返利页面](https://tokenflux.dev/affiliate)。
2. 复制**邀请码**或**邀请链接**（形如 `https://tokenflux.dev/register?aff=INVITE_CODE`）。
3. 分享给好友，好友通过链接注册，或在注册时填入你的邀请码。

::: warning 只能在注册时绑定
邀请关系只在好友**注册时**建立，后续无法补绑，也不能更改。已注册用户无法绑定为被邀请人。

浏览器邀请记录有效期为 **30 天**，若点击链接后超过 30 天才完成注册，邀请关系将无法建立。
:::

## 返利规则

| 项目     | 规则                              |
| -------- | --------------------------------- |
| 返利比例 | 实际比例以邀请返利页面显示为准    |
| 到账时间 | 好友充值完成即时到账              |
| 单人上限 | **每位好友**最多为你带来 `1000🍥` |
| 有效期   | 长期有效                          |

返利上限按被邀请人独立计算，单个被邀请人累计返利达到 `1000🍥` 后，其后续充值不再产生返利，不影响其他被邀请人的返利计算。若某次返利超出该被邀请人的剩余额度，按剩余额度发放。

## 领取返利

返利**不会直接进入账户余额**，而是先进入「可转返利额度」。需在邀请返利页面点击 `转入余额` 转为账户可用余额。

- 转换比例 1:1。
- 每次都是**全额转出**，不能指定金额。
- 转入后就是普通余额，与充值得到的余额没有区别，可用于任何消费。

- **可转返利额度**：当前可转出的额度
- **历史返利额度**：累计获得的总额，只增不减
- **冻结中**：需要等待一段时间才能转出的部分（当前无冻结期时不显示）

## 哪些充值算返利

- 好友的**余额充值**和**订阅购买**都计入返利。
- 好友使用**兑换码**充值同样计入。
- 管理员手动为好友加余额，默认**不计入**返利。

## 注意事项

- 已邀请用户列表中，好友的邮箱会做脱敏显示（如 `a***@e***.com`），最多显示 100 条记录。
- 返利额度只能转入站内余额，**不支持提现**。
- 不要用批量注册、虚假身份等方式刷返利。这类行为违反 [使用政策](/docs/tos/usage-policy)，平台有权封禁账号并不予退款。
