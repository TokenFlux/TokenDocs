# 计费说明

本站采用 `🍥`（推理积分）作为计费单位。**模型广场显示的价格即为最终计费价格**，无需额外计算。

## 计费方式

本站支持两种购买方式：

- **订阅购买**：通常更便宜，有效期为 30 天。
- **按量购买**：按实际使用量计费，无时间限制。

前往 [充值/订阅页面](https://tokenflux.dev/purchase) 即可选择适合的购买方式。

## 价格如何计算

模型的计费包括三部分：输入、输出和缓存。每个部分都有对应的单价。

### 分组倍率

不同的 API Key 分组可能有不同的倍率。分组倍率是基于模型原价计算的，但模型广场显示的价格已经包含了倍率调整——那就是实际支付的价格。

#### Pro 订阅分组

`Pro` 订阅分组目前仅适用于 `Codex App` 和 `Codex CLI`。如果你使用的是其他接入方式，请不要选择 Pro 分组。

#### 数据共享分组

`数据共享` 分组通过出售脱敏后的请求、响应和相关调用数据换取更低价格。使用该分组即表示你同意相关数据在脱敏处理后被提交给合作方或数据购买方，用于数据分析、模型改进、评估或其他产品页明确说明的用途。

如果某个分组涉及数据共享或数据出售，TokenFlux 会在模型广场、购买页、API Key 分组说明或其他产品说明中明确写清楚，不会以默认分组、隐藏选项或模糊描述的方式开启。

**示例**

假设某模型的原价为：
- 输入：`2.5🍥`
- 输出：`15🍥`
- 缓存：`0.25🍥`

当分组倍率为 `1.3` 时，最终计费价格为：
- 输入：`3.25🍥`（2.5 × 1.3）
- 输出：`19.5🍥`（15 × 1.3）
- 缓存：`0.325🍥`（0.25 × 1.3）

这些调整后的价格就是模型广场显示的价格，也是最终支付的价格。具体的模型价格和分组倍率，请在 [模型广场](https://tokenflux.dev/models) 查看。

## 购买方式

### 订阅购买

订阅购买通常更便宜，但有效期为 30 天。

重复购买同一个订阅时：
- 不会并行新增一份同样的订阅
- 本质上是延长时间
- 后一次购买会在上一个订阅失效后生效

### 按量购买

按量购买无时间限制，按实际使用量计费。

前往 [充值/订阅页面](https://tokenflux.dev/purchase) 完成购买。

## 支付与手续费

目前充值已统一通过 Stripe 处理，原支付宝等支付渠道均已迁移至 Stripe。

### Stripe 手续费

Stripe 的手续费原本由两部分组成：

- **固定费用**：每笔交易 2.7 元。
- **浮动费用**：交易总额的 2.2%。

为回馈用户，我们已免除 2.2% 的浮动手续费。调整后，每笔交易仅收取 2.7 元的固定手续费。

### 充值建议

由于每笔交易不论金额大小，平台均需向 Stripe 支付固定的 2.7 元手续费，建议你：

- 尽量单次充值较高金额，减少充值次数。
- 避免分拆多笔小额充值，以降低综合充值成本，提高资金利用率。
