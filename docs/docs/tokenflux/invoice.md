# 发票说明

TokenFlux 目前支持 `invoice` 和大陆普通发票。

## 支持类型

- **Invoice**：使用 Stripe 支付会自动生成。在 [我的订单](https://tokenflux.dev/orders) 中点击对应订单的 `账单` 即可查看（仅限 Stripe 支付订单）。
- **大陆普通发票**：请联系 `daoge` 人工处理，收取 `6%` 服务费。

## 开票主体

本站提供的发票抬头为：`深圳市萌凛科技有限责任公司`。

## 申请流程

如果需要大陆普通发票，请联系 `daoge` 并提供以下信息：

1. 需要开具的发票类型：大陆普通发票。
2. 需要开票的订单或充值记录。
3. 发票抬头、税号等必要信息。
