# 团队

团队让多名成员各自创建和使用 API Key，但统一使用**所有者**的余额、订阅和分组权益。所有者可以为每个成员设置消费限额，并查看全团队的用量。

**直接前往团队页面：[https://tokenflux.dev/team](https://tokenflux.dev/team)**

## 角色

团队只有两种角色：

| 角色            | 说明                                                                             |
| --------------- | -------------------------------------------------------------------------------- |
| 所有者（Owner） | 团队创建者，每个团队有且仅有一个。承担全部团队消费，可管理成员、限额和团队密钥。 |
| 成员（Member）  | 可以创建和使用团队密钥，只能查看自己的用量和限额。                               |

一个账号同一时间只能属于一个团队。团队为单层结构，没有子团队。

## 创建团队

1. 登录后进入 [团队页面](https://tokenflux.dev/team)。
2. 输入团队名称（1–100 个字符）。
3. 点击 `创建团队`。

<div style="text-align: center;">
  <img src="/images/team/create-team.png" alt="TokenFlux 创建团队页面，包含团队名称输入框和创建团队按钮" />
</div>

创建者自动成为该团队唯一的所有者。

> **注意：** 团队消费直接从所有者的余额和订阅中扣除，没有独立的团队钱包或团队充值。

## 邀请成员

仅所有者支持通过邮箱定向邀请，平台不提供邀请码或通用邀请链接。

1. 在团队页的 `概览` 标签中找到邀请区域。
2. 输入对方的邮箱，点击 `发送邀请`。
3. 对方会收到一封含邀请链接的邮件。

<div style="text-align: center;">
  <img src="/images/team/overview.png" alt="TokenFlux 团队概览页，上方为成员列表，下方为受邀邮箱输入框和发送邀请按钮" />
</div>

邀请规则：

- 邀请有效期为 **7 天**，过期后重新发送即可。
- 同一邮箱的邀请有 **60 秒**冷却；每个团队每小时最多发送 **20 封**。
- 同一邮箱在同一团队只保留一条待处理邀请，新邀请会自动撤销旧的。
- 待处理的邀请可以 `重发` 或 `撤销`。

成员容量默认为 **10 人**（不含所有者），实际数值以团队页显示为准。容量只能由平台管理员调整，需要更多席位请联系平台。

## 加入团队

1. 用**受邀邮箱对应的 TokenFlux 账号**登录（没有账号需先注册）。
2. 点击邮件中的链接，页面会弹出邀请详情。
3. 点击 `接受` 加入，或 `拒绝` 放弃。

以下情况会导致加入失败：

- 当前登录账号的邮箱与受邀邮箱不一致
- 邀请已过期或已被撤销
- 当前账户已加入其他团队
- 团队成员已满，或团队处于暂停状态

加入时会自动继承团队当前的「成员默认限额」。

## 成员限额

限额用于控制单个成员的消费上限，分为**日 / 周 / 月**三档，单位与账户余额一致（`🍥`）。

- 填 `0` 表示**不限额**。
- 限额只对普通成员生效，**所有者不受限额约束**。
- 按平台时区的自然日、自然周、自然月滚动，跨周期自动归零。
- 达到任一限额后，该成员的团队请求会被直接拒绝。

所有者可以在 `设置` 标签中配置**成员默认限额**（新成员加入时自动继承，不影响已有成员），也可以在 `概览` 标签中点击某个成员的 `编辑限额`，单独调整并选择重置日/周/月用量。

<div style="text-align: center;">
  <img src="/images/team/settings.png" alt="TokenFlux 团队设置页，包含团队名称、成员默认限额、团队状态和解散团队" />
</div>

成员在 `概览` 标签中可以看到自己的日/周/月限额进度条。

## 团队密钥

团队密钥在 [API 密钥页面](https://tokenflux.dev/keys) 创建，通过右上角的作用域下拉菜单在 `个人密钥` 和 `团队密钥` 之间切换。

<div style="text-align: center;">
  <img src="/images/team/key-scope.png" alt="TokenFlux API 密钥页面右上角的作用域下拉菜单，可选个人密钥或团队密钥" />
</div>

- 所有成员（包括普通成员）都可以创建团队密钥。
- 密钥作用域在创建后**不能**在个人与团队之间转换。
- 团队密钥可选的分组来自**所有者**的分组权益，而不是成员自己的。
- 成员在密钥页只能看到自己创建的密钥。

所有者在团队页的 `团队密钥` 标签中可以看到全团队的密钥，包括名称、状态、脱敏后的密钥、归属成员和绑定分组，并可以对任意密钥执行 `禁用` / `启用` / `删除`。

> **注意：** 完整的密钥明文只在创建时向创建者显示一次，所有者也无法查看。

被所有者禁用的密钥，成员自己无法重新启用，密钥页会显示「团队管理员禁用」和「管理员锁定」标记。

## 查看用量

- **成员**：在 [使用记录](https://tokenflux.dev/usage) 中只能看到自己发起的请求，无法查看其他成员的用量，也看不到所有者的余额和订阅详情。
- **所有者**：使用记录中会同时包含全团队的请求，多出一列「成员」，并额外提供**成员消费趋势**和**成员消费对比**两张图表。

图表会包含区间内有消费的已离队成员，以保证合计金额与团队总消费一致。

## 成员与团队变更

| 操作            | 谁可以执行 | 影响                                                                     |
| --------------- | ---------- | ------------------------------------------------------------------------ |
| 移除成员        | 所有者     | 该成员的全部团队密钥立即禁用，个人密钥不受影响                           |
| 退出团队        | 成员       | 自己的全部团队密钥立即禁用                                               |
| 转让所有权      | 所有者     | 目标成员需在 24 小时内确认；接受后双方角色互换，且双方限额都重置为不限额 |
| 暂停 / 恢复团队 | 所有者     | 暂停期间所有团队密钥立即停止认证，恢复后重新可用                         |
| 解散团队        | 所有者     | 团队、成员关系和全部团队密钥立即停用，**无法撤销**                       |

补充说明：

- 所有者**不能**直接退出团队，必须先转让所有权或解散团队。
- 转让目标必须是本团队当前的普通成员，同一时间只能有一条待处理的转让。
- 暂停/恢复团队、转让所有权、解散团队属于敏感操作。如果页面提示需要二次验证，请先在账号安全设置中启用 TOTP。
- 上述操作对密钥的影响都是立即生效的，不需要等待缓存过期。

## 注意事项

- 离开团队后再重新加入，此前的团队密钥**不会**自动恢复，需要重新创建。
- 团队密钥要求所属成员和付款所有者的账号都处于正常状态，任一方被停用都会导致请求失败。
- 团队成员触发内容风控时，违规记录和处置针对的是**该成员本人**，所有者仅作为付款方被记录，不会因此被误处置。
- 团队消费与所有者的个人消费共用同一套账单，没有独立的团队账单或发票。
